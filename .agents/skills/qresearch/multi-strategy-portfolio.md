# Multi-strategy portfolios

qresearch currently evaluates one frozen market strategy run at a time. It has no portfolio-book, package-operations, event, CSV, or `ops run` command. Do not paper-combine sleeves and describe the result as an engine-tested portfolio.

For future portfolio work, each sleeve must first have a fixed factor decision, immutable config/run lineage, train-only tuning, separate validate/final evidence, full ST filtering, and disclosed overlap/correlation/capacity. Implement and test a dedicated portfolio engine before adding any executable portfolio instructions here.
